# Keybit

Make every keystroke feel better. Keybit brings mechanical keyboard sounds to your Mac in a lightweight menu bar app.

**TipTap is now Keybit.** This repository hosts official downloads and the automatic update feed.

## Download

[Latest release](https://github.com/jswladitya/Keybit-releases/releases/latest) · [All releases](https://github.com/jswladitya/Keybit-releases/releases)

Requires **macOS 14 or later**. Supports **Apple Silicon and Intel Macs**. A valid license key is required.

## Install

1. Download and open the DMG.
2. Drag **Keybit** into **Applications**.
3. Open Keybit, enter your license key, and grant **Input Monitoring** permission when prompted.

If you already use TipTap, quit it before opening Keybit. After a manual installation, remove the old TipTap app once you have confirmed Keybit works. macOS may ask for Input Monitoring permission again.

## Updates and verification

Keybit includes automatic updates. Release downloads are Developer ID signed and contain an Apple-notarized app. Each release includes a SHA-256 checksum and a signed Sparkle update entry.

[Update feed](https://github.com/jswladitya/Keybit-releases/releases/latest/download/appcast.xml)

Earlier TipTap releases remain available in the release history.
